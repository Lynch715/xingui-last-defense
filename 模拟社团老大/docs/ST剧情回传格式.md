# ST剧情回传格式

将下面的格式发给ST。建议一次写3—5条，写完后原样交回，不需要转成JavaScript。

```text
【事件ID】
英文小写，例如：act1_zhaokui_challenge_01

【事件类型】
主线 / 人物链 / 城市事件 / 战后事件 / 结局

【章节与时间】
例如：第一章，第4个月

【触发条件】
例如：赵魁忠诚低于40；玩家连续两次没让他出战

【是否一次性】
是 / 否

【主立绘人物】
填写一人姓名

【共同出场人物】
可填写多人，没有则写“无”

【事件标题】
12—20字，具体、有画面

【正文】
写3—6段，共180—350字。
要有地点、动作和一两句台词。
少喊口号，不替玩家直接决定心情。

【选项A】
按钮文字：
玩家看到的后果提示：
选择后的即时反应：
实际后果：
哪位NPC记住了什么：
后续剧情钩子：

【选项B】
按钮文字：
玩家看到的后果提示：
选择后的即时反应：
实际后果：
哪位NPC记住了什么：
后续剧情钩子：

【选项C】
没有就写“无”

【角色一致性提醒】
写明本事件中不能违背的角色设定。
```

## 角色卡格式

```text
【姓名】
【阵营与职务】
【表面性格】
【真正想要的东西】
【绝对底线】
【最害怕失去什么】
【与主角的旧账】
【说话方式】
【可能背叛主角的原因】
【可能为主角押上性命的原因】
```
