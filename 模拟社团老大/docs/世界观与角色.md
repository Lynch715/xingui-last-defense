# 《模拟社团老大·雾港风云》世界观与角色

## 一句话

沈振海病倒之后，他的孩子接过了只剩一条老街的和联胜。父亲留下的不是王座，而是一本没还完的旧账。

## 城市

雾港是一座架空的南方港口城市。旧城、码头、船厂和批发市场养活了上一代人；新城、娱乐区与中央港区代表着新的钱与新的规则。

沈振海曾经靠和联胜维持一种脆弱的平衡。他重病之后，何万山、方景曜与顾长风分别带走人马和地盘，雾港一夜之间裂成四块。

## 角色表

### 和联胜

- **玩家**：沈振海的孩子，姓名可改。开局并没有足以压住老人的功劳。
- **沈振海**：前任老大。病中交出钥匙、龙头印和旧账簿。
- **赵魁**：战堂负责人。武力与统御出众，对连续失败极度不耐烦。
- **苏曼青**：账房与军师。掌握资金、地盘经营和父亲旧账的真相。
- **程野**：与玩家一起长大的兄弟。擅长招人和收编，但功劳越大，对位置的要求也越高。

### 东潮会

- **何万山**：沈振海昔日副手，认为玩家没资格继承位置。占据南港码头和红星船厂。
- **唐霁**：东潮会主将。重视能力而非姓氏，战败后存在收编可能。

### 万盛堂

- **方景曜**：擅长用钱挖人的新派势力首领。占据金湾娱乐区和东部新城。
- **韩彪**：万盛堂头号猛将。个人武力最高，只愿意跟随正面打败他的人。

### 长风社

- **顾长风**：昔日最年轻的堂主，擅长联盟与策反。占据西关批发市场和北站货场。
- **魏小楼**：情报与谋略人物。永远给自己留第二扇门。

### 独立人物

- **谢九**：没有固定社团的强力头目，要求玩家用胜利证明自己。
- **叶蓉**：熟悉港口商路和地盘经营，能显著改善玩家现金流。
- **阿七**：成长型新人。玩家如何对待俘虏、功臣和街坊，他就会长成什么样的接班人。

## 主要主题

1. **父业不是免死金牌**：旧部敬的是沈振海，不是他的姓。
2. **胜利会制造新问题**：每吞下一块地，就多一群要养的人和一笔没算完的账。
3. **收编比消灭更难**：敌将今天低头，不代表明天不会把刀口调转过来。
4. **阿七是玩家的镜子**：统一雾港不是最后一题，真正的最后一题是你把什么留给下一个人。
